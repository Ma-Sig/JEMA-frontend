Sistema de Gestion de Inventarios Institucionales

Este sistema fue desarrollado como parte del curso de Programación Web, con el objetivo de gestionar de manera eficiente los inventarios institucionales, facilitando el registro, consulta y administración de insumos y equipos utilizados en distintas áreas.

Funcionalidades Principales

🛒 Carro de Compras y FacturaciónPermite simular la generación de una factura hacia proveedores a través de un carrito de compras que agrupa productos requeridos.
📦 Módulo de Gestión de Inventarios (CRUD)Ofrece una administración completa de productos, permitiendo crear, leer, actualizar y eliminar insumos clasificados en las siguientes categorías:

    • Aseo
      Cocina
      Cuentas de usuario
      Tecnología (computadoras, ratones, etc.)
      Aulas y oficinas (sillas, mesas)
      Servicios básicos físicos

    • 🤖 Chatbot de Inventario Asistente automatizado que permite a los usuarios consultar de forma rápida si un producto o recurso está disponible en el inventario.
    🔍 Mashup de Sugerencias Visualización complementaria que compara el inventario actual con fuentes externas o necesidades comunes, sugiriendo posibles adquisiciones adicionales.
